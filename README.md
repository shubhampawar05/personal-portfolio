# Shubham Chopde — Personal Portfolio

A minimal personal portfolio built with vanilla JavaScript, Vite, and custom canvas animations.

## Tech Stack

- HTML5, Vanilla JavaScript (ES Modules)
- CSS3 with custom design tokens
- Vite
- GitHub Actions + GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
```

Production output is generated in the `dist/` directory.
